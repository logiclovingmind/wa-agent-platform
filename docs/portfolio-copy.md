Edit here, hand it back, and the changes go into the deck and into `portfolio.pdf`.

slide's own closing line promises they are not estimates. If they look wrong, the demo
needs reseeding, not the copy.

The icons and the flow diagram are drawn in the HTML, not imported. If a slide below
names an icon, changing the words is safe; changing which icon appears is a code edit.

## 03 — How it works

**Label:** What happens in those seven seconds

**Headline:** Message in, one answer out.

Five steps in a row, each with an icon, a chevron between them.

1. **It arrives** — On the business's own WhatsApp number.
2. **It waits** — Four seconds, so three quick messages are one question.
3. **It reads the business** — Services, prices, hours, the way they speak.
4. **It checks itself** — Anything it should not answer stops here.
5. **One reply** — Never two, and never a holding message.

## 12 — Safety

**Label:** The part nobody else will show you

**Headline:** When it should not answer, it does not.

- **It stops. It does not guess.** Upset, at risk, abusive, or a child: it stops writing

  Every business held apart from every other one, and the agreement is written.
